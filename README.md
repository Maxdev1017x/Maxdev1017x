### Sobre mim

Sou o tipo de desenvolvedor que **não apenas escreve código, mas entrega soluções de negócio**. Seja otimizando um algoritmo para rodar 30% mais rápido ou criando automações que economizam horas de trabalho manual, meu foco é sempre gerar **valor tangível**.

As tecnologias com as quais mais trabalhei são **PHP, JavaScript e Python**.

**O que me move?**
Desafios que exigem mais do que sintaxe: **pensamento crítico, criatividade e proatividade**. Gosto de mergulhar em projetos onde a tecnologia é a ferramenta, mas o impacto na vida do usuário é o objetivo principal.

Vamos construir algo incrível juntos? Me chame no LinkedIn. **O café (ou o chá) é por minha conta!** ☕
